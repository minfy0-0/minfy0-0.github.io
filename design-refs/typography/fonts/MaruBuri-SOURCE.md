# MaruBuri Regular source and license

The preview uses the unmodified `MaruBuri-Regular.ttf` extracted from NAVER's official font archive.

- Font archive: [NAVER MaruBuri ZIP](https://hangeul.naver.com/hangeul_static/webfont/zips/maruburi.zip)
- Official font and copyright page: [NAVER fonts](https://hangeul.naver.com/font)
- Official full license notice: [NAVER Nanum font license](https://help.naver.com/service/30016/contents/18088?osType=PC&lang=ko)
- Local redistribution notice: [MaruBuri-OFL.txt](MaruBuri-OFL.txt)
- Checked: 2026-11-04

NAVER's official pages explicitly apply the Nanum font license terms to MaruBuri. The full notice identifies SIL Open Font License 1.1 and includes MaruBuri among the reserved font names. NAVER states that the English license text is authoritative.

`MaruBuri-OFL.txt` retains the copyright and reserved-name notice shown on NAVER's official license page, followed by the complete standard English OFL 1.1 text. The standard license body was reused from the identical OFL 1.1 text already bundled with this preview's other open fonts; their font-specific copyright notices were not copied. The original font archive did not contain a separate license file.

This preview includes a typeface supplied by NAVER. Preserve this source record and the license notice with the font file.
